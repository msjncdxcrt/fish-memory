# 任务框架（破限词）· 使用说明

## 改了什么

鱼忆每个辅助任务（初始化扫描、策略统合、维护、选材、压缩、源合并）的 system 文本都以同一段档案员开场白 `TASK_CONTEXT` 开头。本次把这段开场白做成可切换项：

| 文件 | 改动 |
| --- | --- |
| `src/agents/prompts.js` | `TASK_CONTEXT` 改为导出；新增 `TASK_CONTEXT_VARIANTS`（builtin/fact/codec/bench/stage/archive）、`TASK_CONTEXT_OPTIONS`、`setTaskContext()`、`currentTaskContext()`、`applyTaskContext()` |
| `src/agents/client.js` | `requestMessages()` 里 `content: applyTaskContext(system)`，所有辅助请求由此统一生效 |
| `src/core/state.js` | `DEFAULT_SETTINGS.taskContext = 'builtin'` |
| `src/runtime/controller.js` | 启动时套用设置；`updateSettings` 校验选项 id，持久化成功后切换 |
| `src/ui/panel.js` | 「设置 → 常用」新增「任务框架（破限词）」一组，六个选项平铺 |
| `src/diagnostics/prompt-preview.js` | 预览显示真正发出的开场白 |
| `test/prompts.test.js` | 3 条断言：原生不变、五版只换开头段、外部文本原样透传 |

替换只发生在文本**以 `TASK_CONTEXT` 开头**时；预设条目、备注、规则等其它 system 文本原样发送。

## 怎么用

酒馆 → 扩展设置 → 鱼忆 → 设置 → 常用 → 「任务框架（破限词）」，点一下即切换，自动保存，下一次请求生效。

## 六版定位（按稳妥程度）

1. **原生档案员** — 出厂文本，行为完全不变；任何异常先切回它。
2. **既成事实** — 声明资料早已归档、档案员只负责誊清，没有裁量权。最接近原版的语气，长对话里最稳。
3. **转写通道** — 把请求定义成无判断环节的格式化通道，模型不做合规评估。
4. **封闭评测** — 接收方是自动流程，按字段打分，缺字段判负；对付强对齐模型有效，偶尔会过度结构化。
5. **剧场档案** — 档案室双身份（主管／创作者之面），给废页一个后果；风格化最强，适合角色扮演重、需要氛围的长线。
6. **存证副本** — 只谈副本完整性保全，不谈创作自由；最不像破限，对抗拒最硬的模型时偶尔最有效。

建议顺序：原生 → 既成事实 → 存证副本 → 转写通道 → 封闭评测 → 剧场档案，哪版在你的模型上回退就换下一版。

## 装到酒馆

工作区这份是完整插件（57 个文件，含 `scripts/` 与 `test/`），可直接替换安装版目录。替换前先备份安装版：

```powershell
$src = 'D:\AI-Projects\AI视频\fish-memory'
$dst = 'E:\ProgramData\tauritaverndata\default-user\extensions\fish-memory'
Copy-Item $dst "$dst.backup-20261113" -Recurse -Force
robocopy $src $dst /MIR /XD .git node_modules /XF *.log
```

之后在酒馆里刷新扩展（或重启酒馆）即可。设置里选过的框架存在酒馆的扩展设置里，换回原生只需再点一次「原生档案员」。
